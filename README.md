Pokemon App
==================================

This project provides a basic API framework, initially designed for experimenting with various functionalities. It currently integrates two primary data sources:

* **NASA's Mars Rover Photos API:** Retrieves images captured by Mars rovers (base code).
* **PokeAPI:** Accesses Pokémon attributes and data.

**Current Focus:**

The primary objective at this stage is to establish a working codebase and explore different API interactions. Reusability and architectural refinements will be prioritized in subsequent iterations.
